\subsection{Problem Formulation}

Define the problem formally. For example, given a set $\mathcal{X} = \{x_1, x_2, \ldots, x_n\}$, we aim to find:

\begin{equation}
    \theta^* = \arg\min_{\theta} \sum_{i=1}^{n} \mathcal{L}(f_\theta(x_i), y_i)
\end{equation}

where $\mathcal{L}$ is the loss function and $f_\theta$ is our model parameterized by $\theta$.

\subsection{Algorithm Description}

Present your algorithm clearly. You can use the algorithm environment:

\begin{algorithm}
\caption{Example Algorithm}
\begin{algorithmic}[1]
\Require Input data $X$, parameters $\theta$
\Ensure Optimized parameters $\theta^*$
\State Initialize $\theta \gets \theta_0$
\For{$t = 1$ to $T$}
    \State Compute gradient $g_t \gets \nabla_\theta \mathcal{L}(\theta)$
    \State Update $\theta \gets \theta - \alpha g_t$
\EndFor
\State \Return $\theta$
\end{algorithmic}
\end{algorithm}
